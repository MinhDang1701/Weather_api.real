# Smart AC Backend

## Cài đặt
Chạy lệnh sau để cài thư viện:
pip install -r requirements.txt

## Chạy chương trình
python app.py

## Mở trên trình duyệt
http://127.0.0.1:5000/weather?lat=16.0471&lon=108.2068

## Mô tả
API này lấy:
- Nhiệt độ
- Độ ẩm

Từ OpenWeatherMap và đưa ra nhiệt độ điều hòa đề xuất.
